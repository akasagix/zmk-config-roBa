補足

  • Arrow レイヤーは pos18+19(J・K)コンボ保持で一時的に有効化(&mo 2)。System・Extra には現状キーマップ上の切替バインディングが見当たりません(ZMK Studio 等での直接切替が前提と思われます)。
  • Mouse レイヤーはトラックボール操作で自動起動(automouse-layer = 3)。Scroll レイヤーは右手 I キー長押し(lt 4)でトラックボール入力がスクロールに切り替わります。
  • Num レイヤーは廃止済み。数値・記号入力は Function レイヤーの数字段・括弧キーに集約されています。
  • Function pos31/32 は単押しで [ ]、Shift併用で { }(専用キーコードではなくベース+Shiftに変更)。
  • Arrow pos41 の「L GUI」は LEFT_WIN と同一キー(HID Left GUI)。Base pos35 と表記を揃えるため roBa.keymap 上では &kp LEFT_WIN を使用しています。Macでは Cmd キーとして機能します。
  • キー上のツールチップ(ホバー)に position 番号を表示 — コンボの key-positions と対応しています。
